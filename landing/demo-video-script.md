## Recording tips (so it looks pro)
- **Hide clutter:** full-screen the browser, hide the bookmarks bar (Cmd+Shift+B), close other tabs.
- **Zoom in a touch:** Cmd+'+' once or twice so text is legible in the recording frame.
- **Move slowly and deliberately.** Pause ~1s on each element before moving. Jerky cursor reads amateur.
- **Tool:** Screen Studio (auto-zoom + smooth cursor — best for the hero cut) or Loom (fastest, instant link).
- **Light mode** records cleaner than dark for this report.
- **Cut the dead air:** trim loading/scrolling lulls in the edit so it stays ~50s.
- **End on the URL** for 3–4s so it's the last thing they see.
